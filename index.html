Como essa loja foi pensada

Recursos de acessibilidade aplicados

🎨

Alto contraste

Paleta escura com amarelo e azul, segura para daltônicos, sem depender de vermelho ou verde para transmitir informação.

🔠

Fonte legível e ajustável

Usamos Atkinson Hyperlegible, desenhada para baixa visão. O tamanho pode ser aumentado pelos botões no canto da tela.

⌨️

Navegação por teclado

Todos os elementos são acessíveis via Tab e Enter. O foco visível em azul indica claramente o elemento ativo.

🔊

Compatível com leitor de tela

Estrutura semântica com ARIA labels, roles e live regions. Cada produto tem descrição completa anunciada automaticamente.

👆

Alvos de toque grandes

Todos os botões têm mínimo de 52px, facilitando o clique para pessoas com baixa precisão motora.

🔗

Link pular navegação

O primeiro elemento da página é um link que pula direto para o conteúdo, evitando repetir o menu em cada página.
